# Course and optional venue submission checklist

## Before submitting the class assignment
- [ ] Instructor accepted revised topic, team spreadsheet updated, Discord team-channel message sent.
- [ ] Actual GitHub repository created; replace README placeholder with URL.
- [ ] All project files in `group_name.zip` (choose consistent name).
- [ ] `README.md` and `requirements.txt` accurate and tested in a fresh environment.
- [ ] Code includes required model artifacts or documented reproducible download location.
- [ ] At least one complete official-data experiment run; results file saved.
- [ ] Research report ≥4 pages with Abstract, Introduction, Related Work, Method, Results, Discussion, Conclusion and Future Work.
- [ ] Paper references real sources and clearly identifies reported vs measured results.
- [ ] Peer evaluations sum to team size x 100 (2 members = 200), private Teams message, cc TAs and instructor, filename firstName_assignmentName.
- [ ] In-person: presentation + Q&A, or online: private ≤3-min video; both members visible/on camera and each explains code.
- [ ] Online: `group_name.txt` containing ONLY the tested private video link, or submit an allowed video file as instructed.

## Optional external venue
- [ ] Do not submit before instructor confirms work sufficient for venue.
- [ ] Check official NLBSE 2027 November 27, 2026 AoE deadline and tool-comp submission form.
- [ ] Check venue 2–4 page competition-paper format; course requires ≥4 pages (maintain separate formatted versions if necessary).
- [ ] Verify organizer's exact inference adapter, time and GFLOPs accounting.
- [ ] Upload anonymized code/replication package to Zenodo/Figshare if class extra credit submission required.
- [ ] Save proof of submission to appropriate track.
